# CodeAlpha_StudentGradeTracker
## Project Overview
The Student Grade Tracker is a Java-based project developed as part of my CodeAlpha Internship – Task 1.

The main purpose of this project is to manage student details and marks and calculate their academic performance.

## Features
- Add and manage student details
- Store student marks using ArrayLists
- Calculate average marks
- Find the highest and lowest scores
- Assign grades based on marks
- Display all student records
- Generate a class summary report

## Technologies Used
- Java
- ArrayList
- Object-Oriented Programming (OOP)

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project in VS Code.
4. Compile the Java file using `javac Task1.java`.
5. Run the program using `java Task1`.
